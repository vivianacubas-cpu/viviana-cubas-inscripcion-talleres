# Sistema de Inscripción a Talleres — AulaLab

Proyecto académico de Angular con múltiples vistas de navegación, formulario Template Driven, validaciones, administración de participantes e indicadores dinámicos.

## Ejecutar en Windows
1. Abre una terminal en `frontend\T06_Prueba-main`.
2. Ejecuta `npm install`.
3. Ejecuta `npm start`.
4. Abre `http://localhost:4200`.

No requiere backend. Los registros se conservan en el almacenamiento local del navegador.
